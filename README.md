# 🛰️ IONOSPHERE

### Analyse der Ionosphäre (TEC) aus GNSS-RINEX-Daten.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white) ![SciPy](https://img.shields.io/badge/SciPy-8CAAE6?style=for-the-badge&logo=scipy&logoColor=white) ![License](https://img.shields.io/badge/License-GPL%20v3-blue?style=for-the-badge)

</div>

---

Ein Python-Toolkit, das aus GNSS-RINEX-Beobachtungsdateien den **Total Electron Content (TEC)** der Ionosphäre berechnet und die Datenqualität prüft – Multi-GNSS-fähig (GPS, GLONASS u. a.).

## ✨ Features

- 📡 TEC-Berechnung aus RINEX-Beobachtungen
- 🛰️ Multi-GNSS-Unterstützung (GPS, GLONASS …)
- 🧹 Eingebaute **RINEX-Qualitätskontrolle** (`rinex_qc.py`)
- 🌐 Gauß-Filter zur räumlichen Glättung

## 🛠️ Tech-Stack

`Python` · `NumPy` · `SciPy` · `georinex`

## 🚀 Schnellstart

```bash
pip install -r requirements.txt
python main.py
```
